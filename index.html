November 25, 2026

I wrapped all of these (blog-like?) entries in <article> tags because I think they fall under the intended use cases described in MDN's reference page for it.

I've also gone through and removed list elements from most of the entries in favor of paragraph elements (except where a list is appropriate).

Similarly, I've replaced the <aside> elements with paragraph elements because the content was still directly related to the main content of this page. I've temporarily added class="follow-up" to those items so that when I do apply CSS styling, I can style them to look more like comments I was making after-the-fact. There's probably a better solution here for that purpose, but I will address it another time.

November 22, 2026

Sent this page through the W3C Markup Validation Service and there were a few errors:

  1. I had my <h2> elements nested inside my lists, but I've now moved them outside. After skimming over 4.3.7 The hgroup element in WHATWG's HTML specs, I'm also under the impression that I shouldn't try to make these into <hgroup> elements, either. I'll consider tagging this whole series of entries as individual <section>s of a larger <article>...eventually (see 4.3.3 The section element in WHATWG's HTML specs).
  2. Inside one of my <meta> elements, I had used the <rel> attribute instead of the <name> attribute for information about the author (me). Same for the <meta> element to which I had added the description.
  3. In the entry for November 15, I had an <aside> element nested inside an unordered list, so I've moved it out.

Otherwise, there are a number of info-level callouts that trailing slashes do nothing for void elements (primarily my <meta> and <link> elements in the <head>), though liking the way they look seems to be a valid enough reason to have them there!
